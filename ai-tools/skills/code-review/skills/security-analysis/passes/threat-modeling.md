# Threat Modeling

## Report As

Report threat-model output as risks, assumptions, and residual-risk follow-ups.
Do not turn a risk into a vulnerability unless the scoped code shows a concrete
exploit path.

- Identify assets, trust boundaries, entry points, actors, attacker goals, and
  assumptions.
- Enumerate abuse cases for each entry point touched by the scoped change.
- Rank risks by likelihood and impact.
- Map each material risk to an existing control, proposed control, or explicit
  residual risk.
